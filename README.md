# Wlauncher

**Лаунчер Minecraft: Java Edition для Windows.**
Официальный вход Microsoft, изолированные сборки, моды из Modrinth и CurseForge — и никакой Java, которую надо ставить самому.

## Что это

Wlauncher ставит Minecraft, держит несколько сборок рядом друг с другом и
запускает любую из них одной кнопкой. Игра заходит под вашим настоящим
аккаунтом Microsoft — это официальная авторизация, а не обход лицензии.

Java ставить не нужно: нужный рантайм (8, 17 или 21 — смотря какая версия игры)
лаунчер скачивает сам по манифесту Mojang.

## Возможности

| Что умеет | Подробности |
| --- | --- |
| **Вход Microsoft** | Настоящая авторизация по коду устройства: открываете страницу, вводите код, дальше лаунчер сам проходит всю цепочку до профиля и проверки лицензии. |
| **Сборки рядом** | У каждой свои версия, загрузчик, моды, миры, ресурспаки и настройки — ничего не смешивается. На полке у каждой карточки своя кнопка «Играть». |
| **Загрузчики** | Fabric · Quilt · Forge · NeoForge — ставятся внутрь сборки, вручную ничего скачивать не надо. |
| **Моды, шейдеры и ресурспаки** | Modrinth и CurseForge в одном каталоге. Выбираются пачкой, ставятся одной кнопкой, обязательные зависимости докачиваются сами — необязательные не приходят без спроса. |
| **`.mrpack`** | Импорт и экспорт: сборка уезжает и приезжает одним файлом. |
| **Quick Play** | Запуск сразу в мир или на сервер, минуя главное меню, — там, где версия игры это умеет. |
| **Статистика** | Сколько наиграно, какие миры и какие серверы есть в сборке, живы ли они. Читается из собственных файлов игры, а не из настроек лаунчера. |
| **Скин и плащ** | Меняются прямо из лаунчера, вместе с историей прошлых скинов. |
| **Офлайн-режим** | Нет сети — игра запустится, если аккаунт уже проходил проверку и с неё прошло меньше 30 дней. Отозванная сессия под это не попадает: она ведёт на повторный вход. |
| **Разбор падений** | Игра упала — лаунчер читает её же крашлог и называет мод, который вероятнее всего виноват: по блоку ошибки загрузчика, по строкам упавшего миксина и по именам пакетов в стектрейсе, совпавшим с установленным jar. |
| **Обновляется само** | Проверяет версию при запуске. Загрузка начинается **только с кнопки**, установка идёт сразу за ней — и об этом написано до нажатия, а не после. |
| **Оформление** | Тёмная тема, фиолетовый акцент, адаптивные три колонки. Тот же язык, что и у остальных программ Wonnder. |

## Скачать

Актуальная версия — на вкладке **[Releases](../../releases/latest)**.

| Файл | Что это |
| --- | --- |
| `Wlauncher-<версия>-setup.exe` | **Установщик — берите его.** Один файл: ни Java, ни .NET, ни распаковки руками |
| `Wlauncher-<версия>-portable.zip` | Тот же лаунчер без установки — для флешки |

**Прав администратора установщик не просит:** программа уходит в
`%LOCALAPPDATA%\Programs\Wlauncher`, ярлыки — в меню «Пуск».

Установщик не подписан, поэтому при первом запуске SmartScreen покажет
«Windows защитила ваш компьютер»: **«Подробнее» → «Всё равно выполнить»**.
Сертификат для подписи кода выдаётся на организацию или ИП и стоит денег —
отсюда предупреждение.

## Что нужно

| | |
| --- | --- |
| Система | Windows 10 или 11, 64-разрядная |
| Java | Не нужна — лаунчер скачивает свою |
| Аккаунт | Microsoft с купленной Minecraft: Java Edition |
| Место | ~175 МБ под сам лаунчер, дальше сколько займут сборки |

Сборки, миры, аккаунты и настройки лежат в `%APPDATA%\Wlauncher` — отдельно от
программы, поэтому обновление их не трогает.

## Удаление

«Установленные приложения» в Windows или `uninstall.exe` в папке программы.
На экране удаления один переключатель: снести сборки и миры или оставить их.
По умолчанию — оставить.

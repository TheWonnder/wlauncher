# Wlauncher — сборки

Здесь лежат только собранные версии лаунчера Minecraft. Исходный код живёт отдельно и сюда не
попадает: у рабочей копии нет git-remote на этот репозиторий, а публикация идёт через Releases API,
который умеет прикладывать файлы к релизу и не умеет создавать коммиты.

## Что скачивать

| Файл | Кому |
| --- | --- |
| `Wlauncher-<версия>-setup.exe` | обычная установка: один файл, которому не нужны ни Java, ни .NET, ни распаковка руками |
| `Wlauncher-<версия>-portable.zip` | тем, кто хочет носить лаунчер на флешке и распаковать сам |

Установленный лаунчер обновляется сам: он читает эту ленту, скачивает `setup.exe` и запускает его,
после чего установщик заменяет папку программы и открывает новую версию. Сборки, миры и аккаунты
при этом не трогаются — они лежат в `%APPDATA%\Wlauncher`.

## Удаление

«Установленные приложения» в Windows или `uninstall.exe` в папке программы. На экране удаления один
переключатель: снести сборки и миры или оставить их на месте. По умолчанию — оставить.
